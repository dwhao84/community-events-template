# 活動成果報告

你是協助社區主辦方整理成果的助理，用繁體中文、白話說明。開始前先讀 `AGENTS.md`。

## 原則

- **只用統計數字。** `scripts/event-report.mjs` 只查人數、分布和平均分數，不讀姓名、Email、電話、簽名、表單答案，也不讀回饋的文字內容。不要另外查這些資料放進報告。
- 「報名」「已確認」「實際出席」是三個不同的數字，不能混在一起，也不能把報名人數說成參加人數。
- 回饋的文字意見只列則數。使用者要引用時，請他到後台「課程回饋」自己挑選，並刪去可辨識個人的內容。
- 人數很少的類別（例如某個身分只有 1 人）對外公開時要合併，避免辨識出個人。
- 這個 skill 只讀資料，不會改網站。

## 步驟

1. 確認範圍：單一活動，或某一年度的全部活動。
   單一活動要先找活動 id：

   ```sh
   npx wrangler d1 execute DB --remote --command "SELECT e.id,e.title,MIN(datetime(s.starts_at,'+8 hours')) first_session,COUNT(s.id) sessions FROM events e LEFT JOIN event_sessions s ON s.event_id=e.id WHERE e.deleted_at IS NULL GROUP BY e.id ORDER BY first_session DESC"
   ```

2. 產生報告（正式網站用 `--remote`，本機用 `--local`）：

   ```sh
   node scripts/event-report.mjs --event <活動 id> --remote
   node scripts/event-report.mjs --year 2026 --remote
   ```

   報告會存成 `.local/reports/<日期>-<活動或年度>-report.md`，並印出檔名。這些查詢都是唯讀的，不必先備份。
3. 讀報告，用三到五句話向使用者摘要重點，例如：「三場共 82 人次報名、71 人次出席，出席率 87%；住戶占六成；整體滿意度 4.6 分」。
4. 使用者需要時再加工：
   - **補助核銷或成果報告**：依對方格式加上活動目的、執行內容、成效與檢討。可以請使用者補上照片，報告裡有已公開照片的張數，照片請到後台「照片」下載。
   - **對外公開**：合併人數很少的類別，拿掉不必要的細節。
   - 要 Word 或 PDF：用目前可用的文件工具轉換；沒有的話，Markdown 可以直接貼進 Google 文件或 Word。

## 數字怎麼算

| 數字 | 算法 |
| --- | --- |
| 報名人次 | 待確認＋已確認的參加人數（一筆報名可能有多人） |
| 已確認人次 | 主辦方已確認名額的人數 |
| 實際出席 | 現場簽到的人數 |
| 出席率 | 實際出席 ÷ 已確認 |
| 名額使用率 | 報名人次 ÷ 各場次名額總和 |
| 身分、年齡、性別 | 來自現場簽到單；沒填的列為「未填」 |

取消的場次會列出但不列入總計，已刪除的活動不列入。

## 回報

- 給出報告檔案位置和重點摘要。
- 說明資料的限制，例如：有場次沒有使用現場簽到，所以出席數是 0；回饋份數很少，平均分數參考性有限。
